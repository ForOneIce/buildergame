# Original cottage prototype asset

`cozy-house.glb` is generated by [the Blender authoring script](../../scripts/art/build_house.py). It is the first stage-5 visual study, not final approved art or a replacement for the five-state town renderer.

- Original generated mesh and embedded texture assets: CC0-1.0, https://creativecommons.org/publicdomain/zero/1.0/.
- Authoring: Codex-assisted Blender 4.5.10 LTS script, guided by the human-supplied complete-house image in `design/`.
- No third-party model pack was imported. Reference-image provenance/license is not inferred or covered by the generated asset dedication.
- `cozy-house.stats.json` records actual export size and geometry count.
- The web viewer adds a procedural fine bump texture and an editable sign label. It approximates fabric response; it does not simulate full fur strands.
- The roof, house and garden are intended to be inspected from all angles. Interior navigation, full five-stage derivation, mobile performance acceptance and exact reference fidelity remain outside this prototype's verified scope.
