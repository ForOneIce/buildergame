> 如果测试配置太麻烦，直接上线验证测试链吧，线上目前没有真实用户，测试链风险可控

## English translation (AI)

If local testing configuration is too cumbersome, deploy and verify on the test network. The online site currently has no real users, and the test-network risk is manageable.

## Scope

Build and verify the optional wallet release, deploy to the existing site, and validate the Ethereum Sepolia flow there. Preserve the standard home page, sample town and unconfigured virtual mailboxes. Keep test-recipient files outside the public repository and import a local backup in the deployed browser for testing. Actual wallet confirmation and verified transaction receipt are separate from automated fixture results or a successful deployment. Do not enable mainnet transfers.
