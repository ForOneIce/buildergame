# A consistent game interface across Buildergame

Date: 2026-09-12. AI tool: Codex.

## Original project instruction

现在有个问题，主页面和小镇实例预览中的ui视觉 控件、页面风格存在割裂。围绕buildergame的理念，我认为视觉设计需要统一和有游戏视觉语言。让体验一致，不存在断层。收集已有的可用的游戏经营类设计组件，评估接下来的视觉统一性方案

## English translation (AI)

There is a visual disconnect between the homepage and the sample town preview: their UI controls and page styles differ. The visual design should be unified around Buildergame's concept and use a game-like visual language, providing a consistent experience without a break between screens. Collect existing reusable design components suitable for management games and evaluate a plan for visual consistency.

## Scope

Research, current-interface audit and a reviewable visual proposal. Candidate assets and the proposed design are not adopted or accepted merely by appearing in the evaluation. Keep the accepted building assets and existing demo behavior intact. See [source assessment](../docs/ui-kit-research.md) and [proposed visual system](../specs/0011-shared-game-interface.md).
