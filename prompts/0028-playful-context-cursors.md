# Add contextual cursors and a door greeting

Date: 2026-09-12. AI tool: Codex.

## Original project instruction

鼠标指针图标显示在创建城镇时显示为一个小斧头，鼠标指针图标在探索项目时显示为脚印。指针在门上时显示为say hi的带手套的手掌，用手开门。以此类推，增加互动趣味细节。

## English translation (AI)

Show a small axe cursor when creating a town and footprints when exploring projects. Over a door, show a gloved hand with a “say hi” greeting, and use the hand to open the door. Add similar playful interaction details.

## Preview interpretation (AI)

Use contextual PNG cursors for build and exploration areas and their entry actions. Door interactions use a white glove, with a closed hand during opening. Keep native text cursors in fields, disabled-control feedback and ordinary touch behavior. Add a responsive doorway hotspot to the existing town poster, an English/Chinese greeting, and a brief door-opening effect that reveals the concise fictional project card. Support keyboard activation and reduced motion.

This is a standalone poster-based visual proposal, not Three.js door picking, navigation or global application. The [review gate](0023-preview-material-direction.md), selected button materials and concise popup remain in effect. Exact reused files and source/license evidence belong in [UI kit research](../docs/ui-kit-research.md); actual QA is recorded after inspection.
