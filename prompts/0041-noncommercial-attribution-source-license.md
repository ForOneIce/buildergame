# Require noncommercial use, attribution and public source

Date: 2026-09-12 (UTC). AI tool: Codex.

## Original project instruction

项目增加license 限制商用 引用时需要署名 必须开源

## English translation (AI)

Add a project license that restricts commercial use, requires attribution when reused or referenced, and requires the source to remain open.

## Implementation interpretation

Commercial-use restrictions are incompatible with describing the license as OSI-approved open source. Codex therefore drafted a custom **noncommercial source-available** license with visible attribution and public corresponding source under the same terms for distributed or network-hosted versions. Private unpublished changes are excluded from that publication trigger. These clauses are implementation choices translating the requested restrictions, not additional verbatim human instructions.

Previously declared CC0 assets, GPL authoring scripts and third-party dependency terms remain separate. The project license grants no new rights in supplied design references, repository data or linked projects. See [LICENSE](../LICENSE) and [NOTICE](../NOTICE).
