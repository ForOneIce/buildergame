# 0014 — Evaluate the visual production pipeline

## Original project instruction

根据视觉效果设计图评估需要使用的技术方案，现在的threejs我不清楚是因为历史累积的内容问题，还是这个技术不能建造符合我审美的效果。搜索可用的技术、开源设计方案组件。我们先把视觉实现做出预期效果，再做别的

## English translation

Evaluate the required technical approach against the visual references. Determine whether the current appearance comes from accumulated implementation choices or limitations of Three.js. Research available technologies and open-source design resources/components. Prioritize achieving the expected visuals before other work.

See [visual pipeline evaluation](../specs/0007-visual-pipeline.md). The human set the visual-first priority; the specific Blender/GLB workflow is an AI recommendation, not a human-approved finished result. Existing exploration work is paused.
