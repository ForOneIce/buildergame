# Make mailbox coin targeting more obvious

Date: 2026-09-13 (UTC). AI tool: Codex.

## Original project instruction

投币鼠标指针hover范围以邮箱为中心扩大半径。避免投币时出现脚印图标。放大金币指针图标大小。让投币更明显一点

## English translation (AI)

Expand the hover radius around the mailbox for the coin pointer. Avoid showing the footprint icon while inserting a coin. Enlarge the coin pointer so the interaction is more obvious.

## Scope

Refine the existing sample-town mailbox target and cursor without modifying buildings or adding a payment feature. [Specification 0013](../specs/0013-sample-mailbox-coins.md#cursor-refinement-0048) records acceptance. Five focused browser groups passed the enlarged target, 48px cursor, activation/flight continuity, neighboring sign/door actions and cancellation behavior; [verification](../docs/verification.md) records exact evidence and limits. Human visual acceptance is not inferred.
