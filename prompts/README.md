# 提示词记录

`0000` 是目录准备工作。从下一轮构思开始使用 `0001`、`0002` 等编号。

建议格式：

```markdown
# NNNN — 主题
- 日期与时区：
- 阶段：构思／规划／实现／验证／提交
- 使用工具：

## 用户原始输入
保存本轮实际输入。敏感内容用占位符替换并注明脱敏。

## 提交给其他 AI 工具的提示词
如无则写“无”；不能把事后摘要当成原始提示词。

## 方案、产物与反馈
保存实际方案或链接到完整规格／规划文件；注明用户反馈和未决项。
```

不追溯伪造此前讨论的逐字文本。背景摘要见 `docs/brief.md`。文件进入 Git 历史；任何敏感材料不得因比赛记录要求而公开。
