# Planning desk music

`Miniature Sky.mp3` is a human-supplied Suno-generated track, integrated at the project owner's request. Its generation prompt is preserved in [instruction 0049](../prompts/0049-planner-suno-music.md).

- Original supplied file: 3,590,270 bytes.
- SHA-256: `2841e093b232826af76e5034e619aa54314c0affe1681eb7d89f6a8c2aa7df9f`.
- FFprobe: 150 seconds, stereo MP3 at 48 kHz, with embedded cover art.
- The unchanged MP3 is imported by Vite and served from the deployment's own assets.
- Playback loops quietly only on the Create town planning desk, after user interaction. The speaker button mutes music and interface sounds together. Leaving the planner stops and resets the track; hidden tabs pause it.
